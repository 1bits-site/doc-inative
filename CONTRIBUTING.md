# Contributing to iNative

The iNative runtime is currently maintained privately. You can still help
the project in ways that matter more than code:

- Reporting IBM i behavior differences (with minimal reproductions)
- Testing compatibility and confirming fixes
- Reporting bugs with logs and versions
- Providing IBM i examples and expected outputs
- Improving or translating this documentation
- Proposing features (the roadmap stays curated: proposing is not promising)
- Sharing reproducible compatibility cases (`CASE-XXXXX`)

## Issues vs Discussions

- **Issue** = actionable work: a bug, an IBM i difference, a feature request,
  a compatibility case, or a docs fix. Use the matching Issue Form.
- **Discussion** = conversation: questions, experiences, IBM i cases under
  study, ideas. A Discussion becomes an Issue when concrete work appears.

Blank issues are disabled: pick a template so reports arrive complete.
