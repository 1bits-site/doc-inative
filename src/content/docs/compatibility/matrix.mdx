## What does "usable" mean?

Never "100% supported". Each area page spells out the covered surface:

```text
RPGLE
├── compile
├── semantic validation
├── runtime
├── CALL
├── RETURN
├── PSDS
├── FileIO
└── debugging
```

See [supported overview](/supported/overview/) for every area.
