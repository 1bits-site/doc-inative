---
title: Contribuir
description: Cómo ayudar a iNative sin acceso al fuente del runtime.
---

El runtime es privado. Igual puedes mover el proyecto:

- Reporta diferencias IBM i ([plantilla](https://github.com/1bits-site/doc-inative/issues/new?template=ibmi-difference.yml))
- Prueba compatibilidad y confirma correcciones
- Reporta bugs ([plantilla](https://github.com/1bits-site/doc-inative/issues/new?template=bug.yml))
- Comparte ejemplos IBM i y salidas esperadas
- Mejora o traduce estos docs (pull requests bienvenidos)
- Propón funcionalidades ([plantilla](https://github.com/1bits-site/doc-inative/issues/new?template=feature-request.yml))
- Comparte casos de compatibilidad reproducibles ([plantilla](https://github.com/1bits-site/doc-inative/issues/new?template=compatibility-case.yml))

Guía completa: [CONTRIBUTING.md](https://github.com/1bits-site/doc-inative/blob/main/CONTRIBUTING.md).
