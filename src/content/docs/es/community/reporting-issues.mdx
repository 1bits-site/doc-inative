Como el fuente del runtime es privado, la comunidad aporta conocimiento:
bugs, casos, comportamiento IBM i, feature requests, documentación.

## Cómo reportar una diferencia IBM i

```text
Versión IBM i:
Versión iNative:

¿Qué intentabas hacer?

Comportamiento IBM i:

Comportamiento iNative:

Esperado:

Actual:

Reproducción mínima:

Logs:
```

`"No funciona"` no se puede corregir. `"IBM i hace X, iNative hace Y, aquí
hay una reproducción de 10 líneas"` sí — y se convierte en un
[caso de compatibilidad](/es/community/ibmi-cases/).

## Elige el formulario correcto

- [🐛 Bug](https://github.com/1bits-site/doc-inative/issues/new?template=bug.yml) — iNative hace algo incorrectamente.
- [🔄 Diferencia IBM i](https://github.com/1bits-site/doc-inative/issues/new?template=ibmi-difference.yml) — alimenta la base de compatibilidad.
- [🚀 Funcionalidad](https://github.com/1bits-site/doc-inative/issues/new?template=feature-request.yml) — propón lo que no existe.
- [🧪 Caso de compatibilidad](https://github.com/1bits-site/doc-inative/issues/new?template=compatibility-case.yml) — un programa IBM i real para espejar.
- [📖 Documentación](https://github.com/1bits-site/doc-inative/issues/new?template=documentation.yml) — errores o huecos en estos docs.

¿Aún no estás seguro? Abre una [Discussion](/es/community/discussions/).
