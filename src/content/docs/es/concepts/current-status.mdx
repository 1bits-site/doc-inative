**iNative 0.1.0** — Early Access · Runtime ABI v5.

Utilizable hoy: RPGLE (compilación, CALL, RETURN, PSDS, File I/O, depuración),
pantallas interactivas 5250, subarchivos SFL, SQLRPGLE, módulos ILE, programas
de servicio, binder, grupos de activación.

Experimental: CL, C/C++. Planificado: mayor cobertura COBOL, QUSRJOBI completa,
conformidad IBM i total.

Detalles: [matriz de soporte](/es/compatibility/matrix/) ·
[limitaciones conocidas](/es/compatibility/limitations/) · [release 0.1.0](/es/releases/0-1-0/).
