## Qué significa "utilizable"

Nunca "100% soportado". Cada área detalla su superficie cubierta:

```text
RPGLE
├── compilación
├── validación semántica
├── runtime
├── CALL
├── RETURN
├── PSDS
├── FileIO
└── depuración
```

Ver [resumen de soporte](/es/supported/overview/) por área.
