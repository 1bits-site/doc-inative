Not everything is an Issue. Use
[Discussions](https://github.com/1bits-site/doc-inative/discussions) for:

- Questions ("How should iNative model activation groups?")
- Experiences ("I tried the 5250 tutorial and…")
- IBM i cases under study ("Can someone test this on 7.5?")
- Ideas not yet ready to be Issues

A Discussion becomes an Issue when concrete, actionable work appears.
(Issues track bugs, differences, features, cases and docs — see
[Report a problem](/community/reporting-issues/).)
