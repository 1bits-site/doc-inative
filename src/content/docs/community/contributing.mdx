---
title: Contributing
description: How to help iNative without access to the runtime source.
---

The runtime is private. You can still move the project forward:

- Report IBM i differences ([template](https://github.com/1bits-site/doc-inative/issues/new?template=ibmi-difference.yml))
- Test compatibility and confirm fixes
- Report bugs ([template](https://github.com/1bits-site/doc-inative/issues/new?template=bug.yml))
- Share IBM i examples and expected outputs
- Improve or translate these docs (pull requests welcome)
- Propose features ([template](https://github.com/1bits-site/doc-inative/issues/new?template=feature-request.yml))
- Share reproducible compatibility cases ([template](https://github.com/1bits-site/doc-inative/issues/new?template=compatibility-case.yml))

Full guide: [CONTRIBUTING.md](https://github.com/1bits-site/doc-inative/blob/main/CONTRIBUTING.md).
