## Is iNative IBM i?

No. It is a local development environment that reproduces ILE workflows.
See [what iNative is not](/concepts/what-is-inative/).

## Can I run production workloads on it?

No. It is for learning, prototyping, and compatibility validation.

## Which languages work?

RPGLE end to end; CL and C/C++ experimentally; COBOL is planned. See the
[support matrix](/compatibility/matrix/).

## How do I report that IBM i behaves differently?

With a minimal reproduction, following [Report a problem](/community/reporting-issues/).

## Is the runtime open source?

The runtime source is private. This documentation site is open source —
typos, translations, examples and clarifications are welcome as pull requests.
