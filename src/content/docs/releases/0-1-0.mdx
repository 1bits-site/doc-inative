## iNative 0.1.0

**Status:** Early Access · **Runtime:** ABI v5

### Supported

RPGLE (compile, CALL, RETURN, PSDS, File I/O, debugging), 5250 + SFL,
SQLRPGLE, ILE modules, service programs, binder, activation groups.

### Known limitations

CL/C++ experimental, COBOL planned, QUSRJOBI partial, no full IBM i
conformance. Details: [limitations](/compatibility/limitations/).

### Not supported

Production workloads, printer files, commitment control, full language
coverages.

- 38/38 internal contract test packages green
