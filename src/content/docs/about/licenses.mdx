title: Third-party Licenses
description: Open-source software shipped with iNative and its licenses.
---

Documenting a dependency does not publish our code nor change its license.
Each package below keeps its own terms; the table states what ships with
the iNative binary. Full inventory with copyright holders:
`legal/THIRD-PARTY-NOTICES.md` (private repo).

| Technology | Use | License |
|---|---|---|
| Go toolchain 1.25 | Runtime / compiler | BSD-3-Clause |
| modernc.org/sqlite (+ SQLite core, public domain) | Local database | BSD-3-Clause |
| gorilla/websocket, pkg/sftp | SSH/Mapepire transport | BSD-2-Clause |
| fsnotify, x/crypto, x/sys, uuid, kr/fs, bigfft, modernc libc/mathutil/memory | Runtime support | BSD-3-Clause |
| go-humanize, go-isatty, go-strftime | Runtime support | MIT |

No GPL, LGPL, AGPL or MPL software ships with iNative. GCC (GPL-3.0 with
exception) is a system requirement, not redistributed. The docs site itself
is generated by Astro/Starlight (MIT); its image tooling (sharp, Apache-2.0)
runs at build time only.
