:::

## Currently supported

<CardGrid stagger>
	<Card title="RPGLE" icon="approve-check">Compile, run, CALL, PSDS, File I/O, debugging</Card>
	<Card title="5250 + SFL" icon="laptop">Interactive screens over TN5250</Card>
	<Card title="SQLRPGLE" icon="database">Embedded SQL alongside RPG</Card>
	<Card title="ILE" icon="puzzle">Modules, service programs, binder, activation groups</Card>
</CardGrid>

## Work in progress

- CL — experimental
- C/C++ — experimental
- COBOL — planned
- Broader IBM i conformance — not yet

## Help us make iNative better

Found a difference with IBM i? [Report it](/community/reporting-issues/) —
behavior reports (`IBM i does X, iNative does Y`) are the most valuable contribution.
