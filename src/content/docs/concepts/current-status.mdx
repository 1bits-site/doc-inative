**iNative 0.1.0** — Early Access · Runtime ABI v5.

Usable today: RPGLE (compile, CALL, RETURN, PSDS, File I/O, debugging),
5250 interactive screens, SFL subfiles, SQLRPGLE, ILE modules, service programs,
binder, activation groups.

Experimental: CL, C/C++. Planned: broader COBOL coverage, QUSRJOBI complete,
full IBM i conformance.
