---
title: "5250"
description: Interactive display files over TN5250.
---

Display files compile from DDS (`CRTDSPF`) to an executable model: records,
fields, DSPATR/COLOR presentation, `CHECK(LC)`, indicators, and command keys
(`CAxx`/`CFxx`, which set `*INxx` — attention keys don't transmit fields).

Covered: `EXFMT` round-trips, subfiles with `ROLLUP`/`ROLLDOWN` paging,
cursor/RRN, function-key dispatch. See [your first 5250 program](/getting-started/first-5250/).
